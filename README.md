# Bangu Tech Solutions Website

A modern, responsive website showcasing web application development services. Clean, simple architecture that works immediately without any server setup.

## 🚀 Quick Start

Simply open the website:
```bash
# Double-click or open in any browser:
index.html
```

No server setup required! The website works immediately.

## 🎨 Customization

### Colors
Edit `assets/css/variables.css`:

```css
:root {
    --primary-color: #2c3e50;     /* Dark blue */
    --secondary-color: #3498db;   /* Blue */
    --accent-color: #e74c3c;      /* Red */
}
```

### Adding Content
Edit the `pageContent` object in `assets/js/app.js` to add new pages or modify existing content.

## 🚢 Deployment

### GitHub Pages

1. Push to GitHub repository
2. Go to repository Settings → Pages
3. Select main branch as source
4. Your site will be available at `https://username.github.io/repository-name`

### Netlify

1. Drag and drop the project folder to netlify.com
2. Your site is instantly deployed

### Any Web Hosting

- Upload all files to your web server
- Point your domain to `index.html`
- Works on any hosting provider
